# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be decent. Critique code, not people. Assume a report comes from someone
who hit a real problem. Harassment, discrimination, or sustained disruption is not
welcome here, in issues, reviews or discussions.

Report a concern to the maintainer through the repository's private channel
(GitHub → Security → Advisories, or a direct message). Reports are handled
confidentially. Maintainers may edit or remove contributions that break this code,
and may block repeat offenders.
